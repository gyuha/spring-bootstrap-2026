### Surprises
- gradle wrapper 부재: PLAN의 verify가 `./gradlew` 가정했으나 wrapper 없음 → 8.14.3으로 부트스트랩 필요 (01-01-SUMMARY.md)
- PLAN 01-04가 자기 모순: DTO를 infrastructure에 두면 application→infrastructure 강제 = D-05 위반 (01-04-SUMMARY.md)
- ArchitectureTest가 생성 시점부터 RED: `consideringAllDependencies()`가 JDK/Spring/test 클래스까지 휩쓸어 168건 오탐 (01-04-SUMMARY.md)
- Docker Desktop 29.4.0 docker-java 협상 실패: "Could not find a valid Docker environment" (01-05-SUMMARY.md)
- Gradle 데몬 재사용으로 env var/systemProp가 fork된 test worker에 미전달 — test task `systemProperty`만 유효 (리뷰 후 실증)

### Patterns
- Wave 기반 병렬 실행: 4 wave, wave 2에서 2개 플랜 동시 (parallel_groups.json)
- 포트/어댑터: domain `SampleRepository`←infra `SampleJpaRepository`, application `SampleQuery`←infra `SampleMapper` (01-04-SUMMARY.md)
- `@Disabled`+본문 주석으로 전방 참조 테스트를 타입 생성 전까지 컴파일 유지 (01-02→01-05)
- 싱글턴 Testcontainers(static init, Ryuk 정리)로 Spring 컨텍스트 캐시 공유 (AbstractIntegrationTest)
- 완료 단언 전 독립 검증(`./gradlew test --rerun-tasks`) (orchestrator)

### Mistakes
- PLAN 01-02의 `@Disabled` 지침 불충분: 미존재 타입 참조는 컴파일 안 됨 → 주석 처리로 보정 (01-02-SUMMARY.md)
- PLAN 01-04가 D-05와 충돌하는 패키지 배치 명시 — 계획 결함 (01-04-SUMMARY.md)
- 공유 build.gradle에 `api.version=1.43` 하드코딩 — 리뷰에서 적발·수정 (commit 198b8e3)
- MyBatis 매핑 중복(별칭 + 전역 설정) — 리뷰에서 정리 (SampleMapper.java)
