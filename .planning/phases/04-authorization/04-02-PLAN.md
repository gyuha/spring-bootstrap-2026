AuthorizationMapper: SampleMapper 형판대로 `@Mapper public interface AuthorizationMapper extends PermissionReadPort {}`. 재귀 CTE는 다중 행·복잡하므로 XML 매퍼(src/main/resources/mybatis/AuthorizationMapper.xml, namespace=FQCN)로 작성한다(@Select 인라인 대신 — 가독성, Claude 재량). MyBatis XML 위치 인식을 위해 application.yml에 mybatis.mapper-locations가 설정돼 있는지 확인하고 없으면 `mybatis.mapper-locations: classpath*:mybatis/*.xml`를 추가한다(설정 추가 시 application.yml을 files_modified에 반영).

findEffectiveGrants(userId, resourceId): 단일 WITH RECURSIVE로 (1) 대상 resourceId의 조상 체인을 resource_hierarchy에서 parent_resource_id 따라 **조상 방향만** 전개(상속 오버리치 방지 — T-04-04), (2) userId의 소속 group_id 집합(group_members), 그 뒤 resource_grants에서 resource_id ∈ 조상체인 AND (user_id = #{userId} OR group_id ∈ 소속그룹)인 raw grant(role, resource_id, source)를 반환한다. **모든 파라미터는 #{} 바인딩만**(절대 ${} 금지 — SQL injection T-04-05). 사이클 가드: PG14+ `CYCLE resource_id SET is_cycle USING path` 또는 `UNION`(중복 제거)으로 무한 루프 방어(Pitfall 1).

listAccessibleResourceIds(userId, action): granted roots(직접+그룹 부여 리소스) → resource_hierarchy를 parent_resource_id로 **하향 전개**(상위 부여가 하위로 상속)하는 재귀 CTE → DISTINCT resource_id. action 매칭은 역할 함의를 고려(역할이 action을 함의하는 grant만 root에 포함 — 도메인 함의를 SQL에서 단순화하기 어려우면 raw role을 반환하고 어댑터/서비스에서 필터하되, SC#3은 ListObjects 결과 포함 여부만 단언하므로 최소 정확성 유지). #{} 만 사용.

PostgresAuthorizationAdapter(infrastructure): `@Component implements AuthorizationPort`. evaluate(userId, resource, action) → PermissionEvaluator.evaluate에 위임(도메인 판정 규칙 재사용). listObjects(userId, action) → AuthorizationMapper.listAccessibleResourceIds 위임. infrastructure→application 의존은 게이트 허용. 이로써 SC#5: 포트(application) ← Postgres 어댑터(infrastructure), 교체 가능 구조.
