    - `Long invite(String emailValue)` → Email 생성 → existsByEmail 선검사, 존재 시 throw EmailAlreadyExists(UX 방어) → User.invite(email) → userRepository.save(user) → saved.getId() 반환. (DB UNIQUE 가 동시성 최종 방어 — IDEN-05/D-06)
    - `void linkIdentity(Long userId, String externalId, String idpDisplayName)` → findById(orElseThrow) → user.linkIdentity(externalId, idpDisplayName) → save. (멱등성·전이 가드는 User 내부 — 서비스는 조율만)
    - `void disable(Long userId)` → findById(orElseThrow) → user.disable() → save (save 가 UserDisabled 발행 트리거 — RESEARCH Pattern 2)
